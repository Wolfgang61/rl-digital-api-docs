# Glossary

This glossary provides definitions of key terms, abbreviations, and concepts used throughout the EPL platform and its APIs.

## A

### API

**Application Programming Interface**

A set of rules and endpoints that enables software applications to communicate with each other.

### Authentication

The process of verifying the identity of a user, application, or system before granting access to protected resources.

## D

### Document Metadata

Descriptive information associated with a document, such as identifiers, publication dates, language, product references, and version information.

### Document Repository

A storage component used to persist and manage electronic product information and related metadata.

## E

### eAAPI

**Electronic Author API**

API used by pharmaceutical companies and service providers to submit, maintain, and publish electronic product information within the EPL platform.

### eCAPI

**Electronic Consumer API**

API used to search, retrieve, and access published electronic product information.

### EPL

**Electronic Product Leaflet**

Digital product information and package leaflet content made available through the EPL platform.

### ePI

**Electronic Product Information**

Structured electronic information related to medicinal products, including package leaflets and associated metadata.

## M

### Metadata

Data that describes other data. Within the EPL platform, metadata is used to identify, classify, and retrieve product information documents.

## O

### OpenAPI

An industry-standard specification for describing REST APIs in a machine-readable format.

### OAuth 2.0

An authorization framework used to secure API access through access tokens.

## P

### PAPI

**Portal API**

API that provides administrative and portal-related functions within the EPL ecosystem.

### Pharmaceutical Company

An organization responsible for creating, managing, and publishing medicinal product information.

### Product Information

Structured information describing a medicinal product, including package leaflet content and associated metadata.

## R

### REST API

**Representational State Transfer API**

An API based on HTTP methods such as GET, POST, PUT, and DELETE.

## S

### Signed Download URL

A temporary, secure URL that allows access to a document for a limited period of time.

### Submission

The process of providing product information and metadata to the EPL platform through the eAAPI.

## V

### Validation

The process of verifying that submitted data complies with technical and business requirements.

### Versioning

The practice of managing API changes through version identifiers to ensure backward compatibility and controlled evolution.
